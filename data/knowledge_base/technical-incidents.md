# Platform Incident Updates

During a confirmed platform outage, support posts updates to the service status
page at least every 30 minutes until resolution. Incident updates should
include affected features, current mitigation, and the time of the next update.

If only one individual reports a slow request, collect the timestamp, endpoint,
and non-sensitive error message before declaring a platform-wide incident.
Never request an API key or full authentication token in a diagnostic ticket.
